핵심 인사이트

도구 접근 권한 ≠ 객체 접근 권한

기존 IAM/OAuth는 "이 에이전트가 파일 읽기 도구를 쓸 수 있는가"만 검증한다. TOLAP은 한 걸음 더 나아가 "어떤 파일을, 어떤 맥락에서, 누구의 대리로 읽는가"까지 제어한다.

🔑

원칙 1 — 최소 권한

에이전트는 현재 작업에 필요한 객체에만 접근. 도구 전체 권한을 부여하지 않는다.

👁️

원칙 2 — 감사 추적

모든 객체 접근은 불변 로그로 기록. 누가, 무엇을, 언제, 왜 접근했는지 CISO에게 보고 가능.

🛑

원칙 3 — 실시간 차단

정책 위반 접근은 실행 전에 차단. 사후 탐지가 아닌 사전 예방 모델.

Agent Safety Should Be a
Runtime Contract

Albus W. Ng, Yi Han, Jusheng Zhang, Wenhao Wang  ·  arxiv.org/abs/2608.11274

RLHF·DPO 등 훈련 기반 안전성만으로는 코드 실행·DB 변경·외부 API 호출을 수행하는 자율 에이전트를 통제할 수 없다. 안전성은 런타임 계약으로 구현되어야 하며, 예방적 차단(Preventive)과 증거 검증(Evidential)의 이중 구조로 작동해야 한다.

Preventive Face

예방적 제어

샌드박스 · 권한 게이트 · 출력 필터 · 궤적 모니터를 통해 위험한 액션이 실행되기 전에 차단한다.

Evidential Face

증거 기반 검증

테스트 실행 결과 · 로그 · 파일 차이 · 인용 근거 등 검증 가능한 증거를 제출해야만 태스크 완료로 인정한다.

핵심 명제

안전한 AI의 단위는 모델이 아니라 검증 가능한 증거를 동반한 에이전트 궤적(Trajectory-with-Checkable-Evidence)이다.

런타임 계약 시뮬레이터

에이전트 액션을 선택하면 런타임 계약 레이어가 어떻게 반응하는지 확인하세요.

런타임 계약 파이프라인
증거 체인 (Evidence Chain)

학술 출판 불균형

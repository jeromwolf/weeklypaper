핵심 인사이트

온디바이스 30B 에이전트의 등장은 프라이버시·컴플라이언스 문제로 클라우드 AI를 사용할 수 없던 금융·의료·법무 기업에 새로운 워크플로우 자동화 경로를 열어줍니다. 4비트 양자화로 단일 GPU에서 실행되며, Apache 2.0 라이선스로 자유롭게 배포·수정이 가능합니다.

비즈니스 분석

Wedge Pitch

클라우드 LLM 사용이 컴플라이언스상 불가한 금융·의료·법무 기업의 워크플로우 자동화 페인을 온프레미스/온디바이스 AI 에이전트 SaaS로 해결합니다.

타겟 고객

데이터 외부 전송이 금지된 중견 금융사·병원·로펌의 IT/운영팀 의사결정자. 클라우드 API 대비 보안 감사 비용 80% 절감이 핵심 가치.

Survival Score Ω

각 대화 인터랙션에 결정론적 생존 점수를 부여. 콘텐츠 신호 + 대화 큐 + 출처 구조를 로지스틱 함수로 결합.

📉

상호작용 기반 감쇠

시간이 아닌 새로운 턴 수(Δn)에 따라 Ω가 감쇠. 완전한 결정론 유지하며 오래된 기억을 자연스럽게 희석.

⚡

Zero LLM 토큰

메모리 관리 루프에서 LLM 호출 완전 제거. CPU만으로 동작하며 Mem0 대비 5~242배 토큰 절감.

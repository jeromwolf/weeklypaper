When Is Smaller Greener?
Right-Sizing Language Models for Agentic AI

Sajid Siraj, Maria Barbati  ·  arXiv 2610.19345

AI 에이전트는 단계마다 LLM을 호출합니다. 하지만 호출 당 비용이 아니라 작업 완료 당 비용으로 비교하면, 작은 모델이 항상 저렴하고 친환경적이라는 통념이 무너집니다.

핵심 인사이트

단계별 신뢰도가 조금만 달라도, 다단계 작업 전체 성공률은 기하급수적으로 벌어집니다. 각 자원(에너지·비용·시간)에는 교차점(crossover)이 존재하며, 작업 길이에 따라 선호 모델이 바뀝니다.

왜 이런 현상이 생기나요?

N단계 작업의 성공률은 각 단계 신뢰도 p를 N번 곱한 pN입니다. 실패한 시도도 자원을 소비하므로, 작업 완료당 에너지는 단계당 에너지 × N ÷ pN이 됩니다.

p가 조금 낮아도 N이 커지면 분모(성공률)가 급격히 떨어져, 전체 비용이 폭발적으로 늘어납니다. 이 교차점이 바로 논문이 말하는 crossover task length입니다.

비즈니스 분석

Wedge Pitch

AI 에이전트를 운영하는 기업의 LLM 비용·에너지 낭비 문제를 작업 복잡도 기반 자동 모델 라우팅 SaaS로 해결합니다. 작업 길이와 유형을 실시간 분석해 교차점 이전엔 소형, 이후엔 대형 모델로 자동 전환합니다.

타겟 고객

월 수천만 원대 LLM API 비용을 지출하며 멀티스텝 에이전트를 운영하는 중대형 SaaS·핀테크·이커머스 AI 팀 엔지니어링 리드. 비용 절감과 탄소 저감을 동시에 요구받는 포지션.

경쟁 환경
  • OpenRouter — 라우팅 레이어지만 에이전트 작업 단위 최적화 미흡
  • Martian — 단일 호출 기준 라우팅, 다단계 성공률 모델 부재
  • LiteLLM — 오픈소스 프록시, 자동 의사결정 로직 없음
